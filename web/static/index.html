MTTR-A for real agents
Agent reasoning can degrade silently while the system keeps running. MTTR-A brings classical reliability measurement to this failure mode: how long does it take an agent to return to coherent operation after drift is detected?

Run a task and watch it live. Each inference call is scored for groundedness against what the agent retrieved. When the score drops, a fault is logged and the clock starts. When the agent recovers on its own, the clock stops. That elapsed time is δt — the same quantity as MTTR in your existing reliability stack, applied to reasoning quality instead of uptime.
